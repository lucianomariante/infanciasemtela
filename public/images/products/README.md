# Imagens de produtos

Salve aqui somente imagens com origem e permissao de uso conhecidas.

Depois, atualize o produto correspondente em `data/product-media.ts`:

```ts
imageUrl: "/images/products/nome-do-produto.webp",
imageAlt: "Descricao objetiva do produto fotografado",
asin: "B0XXXXXXXX",
ageRange: "3 a 5 anos",
```

Nao copie imagens automaticamente da Amazon e nao use hotlink sem autorizacao.
